Cómo levantar / detener
-----------------------
  Levantar : npm run build && npm run start:prod  (API, requiere apps/api/.env)
             npm run dev      (dashboard, http://localhost:5173)
             npm run dev:sim  (simulador; requiere DEVICE_KEY y DEVICE_CODE)
  Detener  : cerrar los procesos node de la API y del dashboard; el contenedor
             PostgreSQL (aquabrain-pg) es independiente.
